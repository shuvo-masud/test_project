##--Java_GUI_Project----##

Project Description- Check Your Tomorrow is a simple Java-based desktop application built using Swing GUI. The program allows users to enter a 3-digit number, then generates a set of random numbers and performs a simulated “luck-based draw” to produce a fun prediction message.

Features- Accepts a 3-digit number from the user

Generates 4 additional random 3-digit numbers

Shuffles all numbers into a random order

Simulates a draw process

Displays outcome-based messages:

Refresh button to reset input and results
